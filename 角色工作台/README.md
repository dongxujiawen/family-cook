# 我的角色收藏 · 本地工作台

一个**只存在你电脑上**的角色收藏工具：新增你喜欢的角色（角色名 + 出处 + 备注），每个角色可上传多张照片和多个视频。手机连家里同一个 WiFi 就能打开查看，数据不出家门、最私密。

> 定位：我喜欢的角色（游戏 / 动漫 / 明星等）。完全免费、零依赖、无需注册、无需联网（照片视频都存在你电脑硬盘）。

---

## 一、怎么启动（在你自己电脑上）

1. 打开「终端」（Mac 叫 终端 / Terminal）
2. 进入这个文件夹（把文件夹拖进终端也可自动填路径）：
   ```bash
   cd 角色工作台
   ```
3. 启动：
   ```bash
   node server.js
   ```
4. 看到 `角色工作台已启动：http://localhost:5050` 就成功了。
   - 电脑上浏览器打开 **http://localhost:5050** 就能用
   - **不要关这个终端窗口**，关了服务就停了

### 停止服务
回到那个终端窗口，按 `Control + C` 即可停止。

---

## 二、手机怎么打开（同一 WiFi）

1. 先确认**手机和电脑连的是同一个 WiFi**
2. 查你电脑的「局域网 IP」：
   - **最简单**：Mac 上打开「系统设置 → 网络 → 点当前 WiFi → 详细信息」，看「IP 地址」（一般是 `192.168.x.x` 或 `10.x.x.x`）
   - 或用终端：`ifconfig | grep "inet "` 找不是 `127.0.0.1` 的那个
3. 手机浏览器（Safari / Chrome 都行）地址栏输入：
   ```
   http://你电脑的IP:5050
   ```
   例如 `http://192.168.1.23:5050`
4. 第一次打开可能弹出「是否允许传入连接」，点**允许**

> 手机和电脑必须同一 WiFi；出门用流量时打不开（这是「本地」的代价，也是它私密的原因）。

---

## 三、怎么用

- **新增角色**：点右下角「＋ 新增角色」→ 填角色名（必填）、出处、备注
- **看角色**：点卡片进入详情，看上传的照片和视频
- **上传照片/视频**：进角色详情 → 点「＋ 上传照片/视频」→ 可一次选多张/多个
- **删除**：详情里「×」删单条媒体；「删除角色」删整个角色（连同照片视频）
- 视频支持拖动进度条播放

## 四、数据存在哪

```
角色工作台/
├─ server.js          # 服务程序
├─ public/index.html  # 界面
└─ data/              # 你的私人数据（建议不要删）
   ├─ characters.json # 角色信息
   └─ uploads/        # 你上传的所有照片、视频
```

数据全部在你电脑本地，不会上传到任何服务器。备份时把这个 `data/` 文件夹拷走即可。

---

## 五、常见问题

- **手机打不开 / 一直转圈**：确认手机和电脑同一 WiFi；确认电脑上那个终端窗口还开着；确认 IP 没填错；Mac 防火墙允许了该端口。
- **端口被占用**：换成别的端口启动，例如 `PORT=6060 node server.js`，手机访问时把 `:5050` 改成对应端口。
- **想换电脑/IP 后还能看**：IP 变了就把手机地址里的 IP 改成新的即可，数据还在电脑上。
- **视频太大上传慢**：家用 WiFi 内网传输很快，几百 MB 也没问题；走的不是公网，不限速。
