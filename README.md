# 家庭点菜 H5 工作台

老公每天点菜，老婆微信打开就能看到，两人数据实时同步。
**零依赖、零注册、零服务器费用**——纯 Node + 静态网页，双击就能跑。

---

## 一、本地运行（你自己先试）

1. 装好 Node（已装可跳过，版本 ≥ 14 即可）
2. 进入 `点菜H5` 目录，运行：
   ```bash
   node server.js
   ```
   看到 `🍳 家庭点菜 H5 已启动：http://localhost:3000` 就成功了
3. 浏览器打开 `http://localhost:3000` → 选「我是老公」或「我是老婆」即可体验

> 数据存在 `点菜H5/data.json`，删掉它就能重置所有菜品和点菜记录。

---

## 二、让老婆在微信里也能打开（关键一步）

本地跑只有你电脑能访问。要让老婆的手机微信也打开，**必须让这个网页有一个公网地址**。两种方案：

### 方案 A：临时用（最快，适合先试试）
在你电脑上用内网穿透把本地服务暴露到公网：
```bash
# 需要装 npx（Node 自带），任选一个
npx localtunnel --port 3000          # 得到一个 https 链接
# 或
npx ngrok http 3000                  # 得到一个 https 链接
```
把生成的 `https://xxxx` 链接发微信给老婆，她点开就能用。
⚠️ 缺点：你电脑关机 / 关掉服务，链接就失效。适合短期体验。

### 方案 B：长期稳定（推荐，7×24 在线）
部署到免费的 Node 托管平台（如 Render / Railway / 腾讯云 CloudBase 云托管），
部署后平台给你一个固定 https 地址，生成二维码发给老婆即可。
- 这些平台一般需要你用 GitHub 账号关联并上传代码（一个小门槛）
- 部署时「启动命令」填 `node server.js`，「端口」填 `3000`

> 微信打开外部网页有时会在底部提示「在浏览器打开」，点右上角 `⋯` → 「在浏览器打开」即可正常操作；或长按链接「发送给朋友」再点开通常能直接看。

---

## 三、日常使用

**老公（点菜）：**
1. 打开页面选「我是老公」，角色会记住，下次直接进
2. 顶部选日期（默认「明天」，符合提前一天点菜）
3. 在菜品库里勾选要吃的菜 → 点「保存点菜」
4. 常吃的菜可在「菜品库管理」里添加 / 删除

**老婆（查看）：**
1. 打开页面选「我是老婆」
2. 看「今天 / 明天」老公点了哪些菜
3. 准备好一道就点一下菜名，标记「已准备」

两人任意一边改动，**另一边 5 秒内自动刷新**，等于自带提醒。

## 四、文件说明

```
点菜H5/
├── server.js        # 后端服务（零依赖，Node 内置 http）
├── package.json     # 启动脚本：npm start
├── public/
│   ├── index.html   # 页面结构
│   ├── style.css    # 手机端样式
│   └── app.js       # 前端逻辑（角色/点菜/查看/轮询）
└── data.json        # 运行时自动生成的数据（菜品+点菜记录）
```

需要加功能（比如历史记录、多天菜单、提醒推送）随时叫我。
